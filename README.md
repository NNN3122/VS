# VS

A webcam-controlled duelling game for Windows. Stand in front of your webcam and **punch, guard and lean to dodge**; your fighter follows. Duel a friend, or team up on a mission across floating islands to fight the Fracture's enemies and its boss.

Pose tracking runs on your own PC. Webcam images are never sent anywhere.

## Download

1. Download **[VS-Windows.zip](https://github.com/NNN3122/VS/releases/latest/download/VS-Windows.zip)** (89 MB) from the [latest release](https://github.com/NNN3122/VS/releases/latest).
2. Unzip it and run `VS\VS.exe`.
3. If Windows says it protected your PC (the game isn't signed), click **More info → Run anyway**.

On first launch, set up the camera and calibrate (about a minute, including 4 quick punches per arm), then try **Practice**.

## Requirements

* Windows 10 or 11, 64-bit
* A graphics card with DirectX 11 compute shaders (any recent NVIDIA, AMD or Intel)
* A webcam, 640x480 at 30 fps or better

## Playing together over the internet

This build connects players over a local network. To play from different places, put both PCs on one virtual network with Tailscale:

1. Both players install [Tailscale](https://tailscale.com/download) and sign in. The host invites the other player to their Tailscale network, or shares their PC with them.
2. **Host:** choose **HOST LAN** (duel) or **HOST MISSION LAN** (co-op). Allow VS through Windows Firewall when asked.
3. **Host:** send the other player your Tailscale IP. It starts with `100.` and is shown in the Tailscale tray icon.
4. **Other player:** choose **JOIN LAN**, type `100.x.x.x:7777` with the host's IP, then **JOIN**. Don't use the `LAN-…` code from the lobby; it points to the host's home network.
5. Both press **READY**.

To check the connection before starting, the other player can run `tailscale ping 100.x.x.x` in a Command Prompt. If it answers but the game can't join, allow VS on public networks too: **Windows Defender Firewall → Allow an app**.

On the same Wi-Fi you don't need Tailscale: host with **HOST LAN** and join with the `LAN-…` code shown in the lobby.

## Problems

The game writes a log to `%USERPROFILE%\AppData\LocalLow\VSGame\VS\Player.log`. Include it when reporting a problem.
